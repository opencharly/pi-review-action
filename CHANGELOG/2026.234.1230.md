# 2026.234.1230 — Drop the CHANGELOG-file requirement; the PR body IS the changelog

## Change

- Removed the B19 CHANGELOG-file requirement from the validator prompt.
  The PR body is the changelog: tag-on-merge creates `CHANGELOG/<calver>.md`
  from the merged PR's title + body at merge time.
- PRs no longer need a CHANGELOG file in the diff nor a `## CHANGELOG`
  section in the body — the full body (Summary / How tested / rulebook
  compliance / classification) is the release-notes source.
- Updated the BLOCK example that referenced the old B19 rule.
